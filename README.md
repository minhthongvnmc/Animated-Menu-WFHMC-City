# 📌 General Information

| Aspect | Details |
| :--- | :--- |
| **Project Name** | Animated Menu: WFHMC City |
| **Initial Release Date** | August 8, 2026 |
| **Author / Studio** | MinhthongVNMC Studio |
| **Category** | Minecraft Custom Main Menu & Dynamic Visual Background |

Animated Menu: WFHMC City transforms Minecraft's default title screen into a stunning, colorful cityscape. Rather than just a standard Minecraft map, it represents a seamless blend of innovative building techniques and advanced graphical enhancements, delivering a peaceful, livable atmosphere set within the familiar WFHMC City.

<h2>✨ Key Features</h2>

<table>
  <tr>
    <td width="50%" valign="top">

#### 🌿 Vibrant Natural Scenery
- Lush green foliage surrounding cozy, rustic wooden structures.
- Blooming flowers, featuring bold red roses that provide striking contrast.
- Clear sky seamlessly reflected on calm waters, enhancing depth and symmetry.

</td>
    <td width="50%" valign="top">

#### ☀️ Realistic Shader Lighting & Shadows
- Dynamic sunlight filtering through tree leaves to produce realistic shadow patches.
- Water rendering with surface refraction and shimmering reflection effects.

#### 🏡 Familiar Urban Environment

</td>
