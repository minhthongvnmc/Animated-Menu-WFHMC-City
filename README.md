# WFHMC City & Animated UI Suite (Bedrock Edition)

**WFHMC City** (formerly *World Flat House Map*) is a large-scale, highly detailed urban development project in Minecraft Bedrock Edition, developed by **MinhthongVNMC Studio**. First released as an alpha version on May 29, 2023, it represents a continuous creative effort to transform a flat world into a vibrant, modern city, complete with dedicated visual enhancements like custom animated main menus.

### ✨ Key Features & Highlights

* **Large-Scale Urban Environment:**
  * Detailed residential zones, wooden housing, fencing, and realistic street lighting.
  * National pride highlight featuring a red flag with a yellow star.
* **Animated Menu & Visual Enhancements:**
  * Transforms the standard title screen into a vibrant cityscape UI with customizable shaders.
  * Lush green foliage, blooming red roses, dynamic sun filtering, and natural water reflection effects.
  * Preserves essential menu navigation buttons (Play, Settings, Skins, Friends) for smooth usability.
